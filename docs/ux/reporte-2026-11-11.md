## Issues (delta post-fix; el #1 de PR21 queda cerrado)

### #1 — [CERRADO] 500 global `border-border` — fix PR22 `bc6e025` verificado
- **Evidencia de cierre:** 24/24 status 200, 0 `ModuleBuildError`, CSS compila, screenshots reales. `postcss.config.js` (v3 + autoprefixer) presente, `postcss.config.mjs` eliminado.

### #2 — [Medium] Warning React `defaultValue/value` en `<select>` (home x3 anchos)
- **Reproduce:** abrir `/` → consola: `Use the defaultValue or value props on <select> instead of setting selected on <option>`.
- **Parche:** controlar el `<select>` (probablemente filtro/orden o form) con `defaultValue`/`value`. Un archivo, sin riesgo.

### #3 — [Medium] Backend `backend.lab-ux.site` inaccesible → vistas con datos en fallback
- **Observado:** `ERR_NAME_NOT_RESOLVED` (36) + `Error fetching proyectos` (3). Las páginas no rompen (200 + layout intacto, overflowX 0), pero Lucía/Carlos verían skeletons/empties en vez de datos reales hasta que el backend responda.
- **Parche:** verificar con backend vivo qué renderiza cada vista con datos (team, proyectos, glosario, diffusion) y confirmar que los empties V3 solo aparecen cuando corresponde.

### #4 — [Low] `landmark-one-main` ausente en 6/8 rutas + `heading-order` / `region` moderate
- Solo home y team tienen `<main>`. Envolver el contenido de proyectos/glosario/metodologias/diffusion/support/login en `<main>`, revisar orden de headings y regiones sin landmark.

### #5 — [Low] `color-contrast` serious en 6 rutas (detalle en tabla axe)
- Tokens con contraste bajo en 1–3 nodos por ruta (support 3, team/login 2). Ajustar tokens y re-correr axe. Es el único High del reporte; fix-forward, no bloquea ship del front sano.

### #6 — [Low] LCP/CLS/INP no medibles en headless-shell + ruido `Deprecated API` x24
- Medir Vitals en browser real ( Represents: `domContentLoaded` 180–375ms es buen indicio). El warning `Deprecated API` es ruido Chrome → candidato a allowlist en `audit-config`.
