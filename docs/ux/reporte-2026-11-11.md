## Issues

### #1 — [Critical] Toda la app responde 500 en dev: `@apply border-border` vs plugin Tailwind v4 — `postcss.config.mjs:2`, `src/styles/globals.css:79`, `package.json:56`
- **Reproduce:** 1. `npm run dev -- --port 3100` → "Ready". 2. Abrir `http://localhost:3100/` (o cualquiera de las 8 rutas). 3. HTTP 500 + overlay `ModuleBuildError: Cannot apply unknown utility class: border-border`.
- **Observado:** `postcss.config.mjs` usa el plugin de **Tailwind v4** (`@tailwindcss/postcss`, declarado en `package.json` devDeps como `@tailwindcss/postcss@^4`) mientras el codebase es **Tailwind v3** (`tailwindcss@^3.4.17`, `tailwind.config.js`, `@tailwind base/components/utilities` en `globals.css`). El compilador v4 no conoce la utilidad `border-border` generada por el theme v3 → falla **todo** el CSS → 500 en todas las rutas. Ya listado como tech debt P0/P2 en AGENTS.md ("postcss.config.js + .mjs duplicados", "breakpoint prod"). Evidencia: `docs/ux/qa-results.json` (24 x status 500 + `pageerror` ModuleBuildError), 24 screenshots en `docs/ux/shots/`.
- **Esperado:** home y las 7 rutas renderizan con tokens V1, TeamCard V2, cards V2, empties V3.
- **Parche mínimo sugerido (para el equipo, fuera del alcance docs-only de este PR):** alinear PostCSS con Tailwind v3 (plugin `tailwindcss` + `autoprefixer`, que ya es dependencia) o migrar CSS a v4 (`@import "tailwindcss"`). Verificar con `npm run build`. No se toca en este PR por la regla "solo docs/ux/".
- **Severidad:** Critical (bloquea el 100% de la verificación; en prod equivaldría a sitio caído si el build usara la misma config).

### #2 — [High] Backend `backend.lab-ux.site` inaccesible desde la red de QA — `src/constans/Api.ts` (env `NEXT_PUBLIC_API_URL`)
- **Reproduce:** `fetch('https://backend.lab-ux.site/')` → `TypeError: fetch failed` (timeout/DNS). Sin credenciales expuestas; no se reintentó con PII.
- **Observado / Esperado:** aun con el front sano, `fetchContenidos`, `fetchUsers`, glosario y eventos caerían a skeletons/mocks. Verificar tras el fix del #1 si es solo red local o caída real, y documentar qué ve Lucía/Carlos (skeletons vs empties V3).
- **Severidad:** High (datos reales no verificables; riesgo de home/team/diffusion vacíos en prod).

### #3 — [Medium] Sin baseline visual commiteado ⇒ regresión visual INCONCLUSIVE — `docs/ux/shots/`
- **Observado:** es la primera captura sistemática (24 PNG). No hay contra qué comparar.
- **Parche:** tras el fix del #1, re-capturar las 24 y proponerlas como baseline del PR siguiente; el set actual sirve como baseline del "estado 500" (detector de regresiones a error).

### #4 — [Medium] Advertencia de entorno: `@next/swc-win32-x64-msvc no es una aplicación Win32 válida` + `warning: Deprecated API for given entry type` (24/24)
- **Observado:** el binario SWC no carga en este Windows; Next hace fallback (compila igual, más lento). El `warning` aparece en cada navegación.
- **Parche:** reinstalar `node_modules` (`npm install --legacy-peer-deps`) o fijar plataforma del optional dep; confirmar que no aparece en CI limpio.
- **Severidad:** Medium (ruido + riesgo de divergencia de build local vs CI).

### #5 — [Low] Foco amarillo `#CA8A04`, landmarks y `aria-live` del glosario sin verificar — varias vistas
- **Observado:** nada renderizó; `main/nav/footer` ausentes en las 24 (solo overlay dev), `aria-live` solo del overlay, 0 imágenes (alt n/a), 0 links (dead-links n/a).
- **Parche:** checklist diferido al re-run post-fix (incluye debounce del glosario, teclado end-to-end, contraste AA).
- **Severidad:** Low solo porque está bloqueado, no porque sea poco importante — es criterio de SHIP.

### #6 — [Low] Duplicado tech-debt ya registrado (no re-abrir, solo constancia QA): layouts anidan `<html>`, auth solo localStorage, typo `constans/`, `components.json` apunta a `styles/` inexistente
